# Mogiliovcai

## Santrauka

Bychovco kronikos rankraštis buvo aptiktas Aleksandro Bychovco Mogiliovcų dvaro bibliotekoje. Mogiliovcai šiame gabale siejami su rankraščio radimo vieta.
